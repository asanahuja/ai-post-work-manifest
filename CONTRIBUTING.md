# Contributing

This repository is publicly readable and open to **discussion, criticism, corrections and proposed improvements**, but the canonical manifesto is editorially controlled.

## Final approval

All official modifications require explicit approval by:

**Albert Sanahuja Llopis**

Submitting a suggestion, issue, pull request or translation does not imply that the proposed text has been accepted.

## Useful contributions

Contributions are especially welcome when they:

- identify factual errors
- provide strong primary or academic sources
- expose hidden assumptions
- present serious counterarguments
- improve conceptual clarity
- identify conflicts between principles
- improve translations
- improve accessibility or readability
- distinguish evidence from speculation
- identify governance, safety or sustainability risks

## Please avoid

- partisan propaganda
- personal attacks
- unsupported factual assertions
- presenting speculative AI scenarios as certainty
- operational instructions for harmful activities
- changing the ideological framing without explaining the conceptual impact
- silently modifying translations independently from the canonical Catalan version

## Suggested proposal format

```text
CHANGE PROPOSAL
Base version:
Proposed by:
Date:
Sections affected:
Reason:
Proposed text:
Conceptual impact:
Evidence / references:
Target version:
```

## Editorial process

1. proposal or issue
2. discussion and evidence review
3. draft modification
4. translation synchronization when needed
5. explicit approval by Albert Sanahuja Llopis
6. merge
7. changelog update
8. version/tag when appropriate

See `AGENTS.md` for AI-agent-specific rules.

## Licensing note

Submitting a proposed contribution does not change the copyright or licensing terms of the canonical manifesto. Contributors should only submit material they have the right to share.

The copyright holder may accept, reject, rewrite or incorporate suggestions into a later version.
